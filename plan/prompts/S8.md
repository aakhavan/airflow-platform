# S8: Terraform module for GCP, tested with mock providers

**Commands (permission rules):** run each command as a single `uv run ...` call. Don't use `&&`, `;`, pipes, PowerShell expressions, `uv lock`, `uv sync` or bare `python`/`pytest`. `uv run` locks and syncs by itself. Use: `uv run pytest -q`, `uv run python -m airflow_platform.stack ...`, `uv run python plan/accept/<script>.py`. Docker and Terraform go through the stack module or the acceptance scripts.

Contract: `docs/spec.md` §9 (GCP column and rules) and §12. Same conventions as S7. Read `terraform/modules/airflow-vm-aws/` for style. **Never apply or plan against GCP.**

Build:
1. `terraform/modules/airflow-vm-gcp/`:
   - `versions.tf`: pin `hashicorp/google` to a version that supports `scheduling.max_run_duration` and `instance_termination_action`; check the changelog and record the version.
   - `variables.tf`: `project_id`, `region="europe-west3"`, `zone="europe-west3-a"`, `name`, `machine_type="e2-medium"`, `network="default"`, `repo_url`, `repo_ref`, `secret_names`, `ttl_minutes=0`, `enable_registry=false`, `labels`.
   - `main.tf`:
     - a dedicated service account;
     - `google_secret_manager_secret` slots (no versions) with `secretAccessor` bound per secret to the SA only;
     - `google_compute_instance` with Ubuntu 24.04 LTS, pd-balanced 30 GB, Shielded VM, no external IP (`access_config` absent) plus a **Cloud NAT** for egress. If NAT is more than a few cents a day, make it a variable and record the cost note;
     - startup via the shared template with `cloud = "gcp"`;
     - `scheduling { max_run_duration, instance_termination_action = "DELETE" }` with `provisioning_model = "STANDARD"` when `ttl_minutes > 0`, as a dynamic block;
     - a firewall allowing only `35.235.240.0/20` on tcp 22 and 8080 to the instance's tag;
     - an Artifact Registry repo with `count`.
   - `outputs.tf`.
2. `terraform/modules/airflow-vm-gcp/tests/main.tftest.hcl`: `mock_provider "google"`, with runs asserting no `0.0.0.0/0` source range, IAP-only sources, no external IP, TTL scheduling present only when `ttl_minutes > 0`, no registry by default, and secret slots without versions.
3. `terraform/envs/gcp/`: same shape as `envs/aws`.
4. Keep the cloud-init template shared. If GCP needs something AWS doesn't, branch on `cloud` inside the template. Never fork the file.

Tests (offline pytest): extend the S7 tests to cover `envs/gcp`, plus `test_gcp_module_has_no_external_ip_block`.

Done when `plan/accept/accept_s8.py` passes (fmt, validate and test for the GCP module and env; the AWS module still passes).
