# S9: Operator scripts and the terraform CI job

Contract: `docs/spec.md` §10, §11 (terraform job) and D15. Rules: `AGENTS.md`. **Run every cloud script only with `-WhatIf`.** No agent call may reach AWS or GCP.

Build (PowerShell 7, `[CmdletBinding(SupportsShouldProcess)]`, `Set-StrictMode -Version Latest`, `$ErrorActionPreference='Stop'`):
1. `scripts/plan.ps1 -Target aws|gcp`: checks that the CLI is installed and logged in (`aws sts get-caller-identity` / `gcloud auth list`; printing only the account id or email), `terraform init` + `plan -out` in `envs/<target>`, and writes a summary to `logs/plan-<target>-<ts>.txt`.
2. `scripts/smoke.ps1 -Target aws|gcp [-Yes] [-Force] [-KeepOnFailure]`:
   1. refuses if `envs/<target>` already has resources in state (unless `-Force`);
   2. prints the resources and a rough cost line (instance hourly price × 1.5 h + disk; a table in the script, marked "approximate, check the plan");
   3. asks for `y` unless `-Yes`;
   4. `apply -var ttl_minutes=90 -var name=airflow-platform-smoke`;
   5. waits for SSM/IAP;
   6. opens the tunnel as a background job;
   7. `stack status` on the tunnel until healthy (timeout 15 min);
   8. triggers `hello_workload` and waits for success.

   A `finally` block (unless `-KeepOnFailure`) runs `destroy -auto-approve`, then queries for leftover instances named or tagged `airflow-platform-smoke`, failing loudly if any remain. It writes `logs/smoke-<target>-<ts>.json` with each phase's status and timing.
3. `scripts/tunnel.ps1 -Target aws|gcp [-LocalPort 8080]`: reads the instance from the Terraform outputs and runs the port-forward.
4. `scripts/remote-state.ps1 -Target aws|gcp -Bucket <name>`: creates a private, versioned, encrypted bucket (S3 with block-public-access / GCS with uniform access + public access prevention), writes `envs/<target>/backend.tf`, and runs `terraform init -migrate-state`. It prints a reminder that committing `backend.tf` is Amir's choice.
5. `stack.py`: a `--url` option on `status`, `trigger` and `wait`, so they work through a tunnel.
6. `.github/workflows/ci.yml`: add the `terraform` job (§11): `hashicorp/setup-terraform` (pinned), `fmt -check -recursive`, `init -backend=false` + `validate` for both envs, `terraform-linters/setup-tflint` + `tflint --recursive`, and `terraform test` in both modules.
7. `docs/runbook.md`: the one-time steps that are Amir's (a €5 budget alert per account, CLI logins, filling the secret slots after the first apply) and how to run a smoke test, read its log and clean up by hand if the script dies.

Tests (offline): `test_scripts_support_whatif`, `test_smoke_destroys_in_finally` (a structural check of the script), `test_no_script_echoes_secret_values` (no `Write-Host`/`Write-Output` of variables whose name contains `secret`, `password` or `token`), `test_ci_has_terraform_job`.

Done when `plan/accept/accept_s9.py` passes. It runs each script with `-WhatIf` in an environment with the cloud CLIs hidden from PATH and asserts zero cloud calls (a stub `aws`/`gcloud` on PATH that records invocations).
