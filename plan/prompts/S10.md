# S10: README, architecture diagram and the learning page

**Commands (permission rules):** run each command as a single `uv run ...` call. Don't use `&&`, `;`, pipes, PowerShell expressions, `uv lock`, `uv sync` or bare `python`/`pytest`. `uv run` locks and syncs by itself. Use: `uv run pytest -q`, `uv run python -m airflow_platform.stack ...`, `uv run python plan/accept/<script>.py`. Docker and Terraform go through the stack module or the acceptance scripts.

Contract: `docs/spec.md` §1–§3; ADRs 0001–0003; `CONTEXT.md`. Rules: `AGENTS.md`.

Write for a stranger and for Amir (not a native English speaker; plain words, short sentences).

Build:
1. `README.md`:
   - **What / why:** a reusable, self-hosted Airflow platform; the dependency problem and the thin-orchestrator answer.
   - **Quick start** (Windows and Linux): prerequisites (Docker Desktop, uv, PowerShell 7), `pwsh scripts/up.ps1`, open `localhost:8080`, trigger `hello_workload`.
   - **Add a project:** the YAML entry and what you get (bundle, nav entry, DAG tab, task link).
   - **Targets:** local (built and tested), aws/gcp (Terraform tested with mock providers; smoke-tested: fill in from `logs/smoke-*.json` if any exist, otherwise "not yet").
   - **Cost and safety:** the TTL, `smoke.ps1`, the budget alert.
   - **Limits and future targets:** single VM; Kubernetes + Helm; managed DB; Git bundles; `build run` with human-in-the-loop.
   - **Repo map:** links to the spec, the ADRs, `CONTEXT.md` and `docs/projects/governor.md`.
2. `docs/architecture.md`: one Mermaid diagram of the local target (services, docker-proxy, workloads, projects, project views) and one of a cloud target (VM, cloud-init, secret slots, tunnel, TTL).
3. `docs/learning/airflow-platform.md`: a plain-language lesson. For each design choice (thin orchestrator, socket proxy, DAG bundles, external views, VM + compose, TTL, mock-provider tests): what it is, the problem it solves, the data-engineering analogy, and "what would change in a company". End with 8 interview-style questions and short answers.
4. `LICENSE`: MIT, copyright Amir Akhavan, 2026.
5. Optional, and cut first: a `checkov` job in CI with `soft_fail: true` (pinned action).
