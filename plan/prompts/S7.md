# S7: Terraform module for AWS, tested with mock providers

**Commands (permission rules):** run each command as a single `uv run ...` call. Don't use `&&`, `;`, pipes, PowerShell expressions, `uv lock`, `uv sync` or bare `python`/`pytest`. `uv run` locks and syncs by itself. Use: `uv run pytest -q`, `uv run python -m airflow_platform.stack ...`, `uv run python plan/accept/<script>.py`. Docker and Terraform go through the stack module or the acceptance scripts.

Contract: `docs/spec.md` §9 (AWS column and rules) and §12 (S7/S8 row). ADR 0002. Rules: `AGENTS.md`. **Never apply or plan against AWS.**

Build:
1. `terraform/templates/cloud-init.yaml.tftpl` (shared with S8). Variables: `repo_url`, `repo_ref`, `cloud` (`aws`|`gcp`), `secret_names` (list), `ttl_minutes`, `region`. Steps, as §9 says:
   - install Docker Engine and the compose plugin (official apt repo), plus `uv`;
   - clone the repo at `repo_ref`;
   - for each secret name, fetch the value with the cloud CLI into `stack/.env` (one `KEY=value` line each; the slot name maps to the key);
   - `uv run python -m airflow_platform.stack up --projects projects/ci.yaml`;
   - if `ttl_minutes > 0`, `shutdown -h +<ttl_minutes>`.

   **No secret value is ever a Terraform variable.**
2. `terraform/modules/airflow-vm-aws/`: `versions.tf` (pin `required_version` to the installed Terraform minor, ≥ 1.7; pin the `hashicorp/aws` major), `variables.tf` (`name`, `instance_type="t3.medium"`, `subnet_id=null` meaning the default VPC, `repo_url`, `repo_ref`, `secret_names=["AIRFLOW__API_AUTH__JWT_SECRET", ...]` (choose what the stack really needs and document it), `ttl_minutes=0`, `enable_registry=false`, `tags`), `main.tf` (per §9: Ubuntu 24.04 AMI from the SSM public parameter, gp3 30 GB encrypted, IMDSv2 required, a security group with **no ingress**, instance profile with SSM core + a policy allowing `secretsmanager:GetSecretValue` on its own slot ARNs only, secret slots without versions, an ECR repo with `count`, `instance_initiated_shutdown_behavior = ttl_minutes > 0 ? "terminate" : "stop"`), `outputs.tf`.
3. `terraform/modules/airflow-vm-aws/tests/main.tftest.hcl`: `mock_provider "aws"` with `override_data` for the AMI parameter and the default VPC. `command = plan` runs assert the 7 rules in §9 that apply to AWS. Add a second `run` with `ttl_minutes = 90` and `enable_registry = true`.
4. `terraform/envs/aws/`: `main.tf` calling the module, `variables.tf`, `terraform.tfvars.example`, `outputs.tf`. No backend block.
5. `stack/versions.yaml`: the Terraform version and the provider version.

Tests (offline pytest): `test_no_tfvars_committed`, `test_no_backend_block_in_envs`, `test_cloud_init_has_no_secret_values` (the template references only names), `test_template_shared_by_both_clouds_has_cloud_switch`.

Done when `plan/accept/accept_s7.py` passes. It runs `terraform fmt -check`, `init -backend=false`, `validate` in the module and in `envs/aws`, then `terraform test` in the module. If Terraform isn't installed on PATH, use the `hashicorp/terraform:<pinned>` Docker image and record that in `NOTES.md`.
